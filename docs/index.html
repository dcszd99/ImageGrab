产品介绍

解决电商图片保存的三大痛点

做电商运营、选品分析、素材采集时，商品图往往散落在页面各处，手动保存费时费力。

图片分散难收集

主图、详情图、轮播图藏在不同的 DOM 节点与懒加载属性里，手动找全很困难。

手动保存效率低

一张张「右键 → 另存为」重复操作，几十张图下来耗时又容易漏、容易重。

格式不统一

jpg、webp、gif 混杂，整理归档麻烦。图提取自动统一转为 PNG，方便后续使用。

核心功能

六项能力，一步到位

从提取到下载，全流程自动化，专为电商商品图场景设计。

一键提取

自动扫描页面所有商品图，兼容 srcset、data-src、懒加载与背景图。

智能过滤

自动排除图标、logo、占位图与过小的无效图片，只留真正有用的商品图。

集中预览

新标签页网格化展示所有图片，缩略图与尺寸信息一目了然。

自由勾选

支持全选、反选、按需勾选，想下哪张下哪张，灵活可控。

统一 PNG

通过 canvas 将 jpg、webp 等统一转为 PNG，跨域图片同样处理。

批量下载

一键保存到本地默认目录，文件名自动编号，进度与结果实时反馈。

安装步骤

四步完成安装

无需编译、无需打包，解压后加载即可使用。

  1. 1

    下载并解压插件

    下载插件压缩包，解压到本地一个固定文件夹（例如 ImageGrab）。

  2. 2

    打开扩展管理页

    打开 Chrome，在地址栏输入 chrome://extensions 并回车。

  3. 3

    开启开发者模式

    点击页面右上角的「开发者模式」开关，将其打开。

  4. 4

    加载已解压的扩展程序

    点击「加载已解压的扩展程序」，选择刚才解压出的 ImageGrab 文件夹即可。

开始高效保存商品图片

安装图提取，把重复劳动交给插件，专注真正重要的事。
